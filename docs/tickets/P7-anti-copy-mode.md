# P7 – Anti-copy mode

- **Epic:** Proposed extras (optional)
- **Status:** proposed (optional)
- **Index:** [all tickets](README.md)

**Depends on:** T10, T12

A guild setting, **off by default**: other members' individual picks stay hidden until you save your own pick for that match; aggregates stay visible. The base requirement says picks are visible before the start, so this is only an option for when copying becomes a problem. Size S; depends on T10 and T12.
